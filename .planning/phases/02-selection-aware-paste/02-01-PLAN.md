<objective>

Read AX selection state (range + selected text + leading whitespace of cursor's line) immediately before pasting, attach it to `PasteToken`, and inject mirrored leading whitespace after each `\n` in the text being pasted so voice "new line" tokens align with surrounding indent. Failure modes degrade silently per D-01.

<known_limitations>
<!-- Document and ship — do NOT try to solve here. -->

1. **`Paster.replace()` indent injection scope** — `replace()` receives Claude-cleaned `expanded` (the pre-indent text). When cleanup fires, the replacement paste will not have indent injected. This is accepted scope per D-05 (indent injection lives in `pasteTracked` only). Note as known limitation in PLAN-SUMMARY.md; track as Phase 2.1 follow-up.

2. **UTF-16 vs grapheme cluster alignment** — `kAXSelectedTextRangeAttribute` returns a `CFRange` in characters. Swift `String.index(_:offsetBy:)` operates on grapheme clusters. Documents containing emoji or surrogate pairs before the cursor may misalign by one offset position. Mitigation already in plan: every `index(_:offsetBy:limitedBy:)` call is guarded with `limitedBy: text.endIndex`, so misalignment never crashes — at worst, leadingWhitespace falls back to `""` or a wrong-by-one-character substring extracts. Document as known caveat. Fix path (use `utf16.index`) deferred until empirical evidence of breakage.

3. **`replace()` failure path does not restore selection** — D-07 explicitly defers this. Recorded selection is bookkeeping only in this phase.
</known_limitations>

```swift
/// Captured AX state of the focused text element at paste time.
/// All fields nil-tolerant so callers can degrade gracefully when the
/// AX tree doesn't expose what we need (e.g. Electron apps without
/// proper text roles).
struct SelectionState {
    /// CFRange of the selection within the focused element's value.
    /// `length == 0` means insertion-point-only (no selection).
    let selectionRange: CFRange
    /// The selected substring. nil when `selectionRange.length == 0` or
    /// when `kAXValueAttribute` was unavailable.
    let selectedText: String?

    /// `selectionRange.location`. nil when `kAXValueAttribute` was
    /// unavailable. Empty string is a valid value (cursor at column 0
    /// of an unindented line) — distinguishes from "couldn't read".
    let leadingWhitespace: String?
}
```

**Step 4.** Add three private static helpers on `Paster`:

```swift
/// Reads selection range, selected text, and leading whitespace of the
/// cursor's line from the system-wide focused element. Returns nil on
/// any AX failure (per D-01 graceful degrade — no NSLog, no UI).
///
/// Always reads `kAXValueAttribute` (one extra AX call) so `selectedText`
/// is populated even when the to-be-pasted text has no `\n`. Per RESEARCH
/// open-question 3.
private static func captureSelectionState() -> SelectionState? {
    let systemWide = AXUIElementCreateSystemWide()
    var focusedRef: CFTypeRef?
    guard AXUIElementCopyAttributeValue(
        systemWide, kAXFocusedUIElementAttribute as CFString, &focusedRef
    ) == .success, let focused = focusedRef else { return nil }

    let element = focused as! AXUIElement
    // 0.5 SECONDS — parameter is `timeoutInSeconds: Float`. NOT milliseconds.
    // Set on `element`, NOT `systemWide` (would set process-wide global).
    AXUIElementSetMessagingTimeout(element, 0.5)

    var rangeRef: CFTypeRef?
    guard AXUIElementCopyAttributeValue(
        element, kAXSelectedTextRangeAttribute as CFString, &rangeRef
    ) == .success, let axVal = rangeRef else { return nil }

    var cfRange = CFRange(location: 0, length: 0)
    guard AXValueGetValue(axVal as! AXValue, .cfRange, &cfRange) else { return nil }

    // Read full text. Bounded by the 0.5s per-element timeout above.
    var textRef: CFTypeRef?
    let fullText: String?
    if AXUIElementCopyAttributeValue(
        element, kAXValueAttribute as CFString, &textRef
    ) == .success, let s = textRef as? String {
        fullText = s
    } else {
        fullText = nil
    }

    let selectedText: String?
    if cfRange.length > 0, let text = fullText {
        let start = text.index(text.startIndex, offsetBy: cfRange.location,
                               limitedBy: text.endIndex) ?? text.endIndex
        let end   = text.index(start, offsetBy: cfRange.length,
                               limitedBy: text.endIndex) ?? text.endIndex
        selectedText = String(text[start..<end])
    } else {
        selectedText = nil
    }

    let leadingWhitespace: String?
    if let text = fullText {
        leadingWhitespace = extractLeadingWhitespace(from: text,
                                                     cursorLocation: cfRange.location)
    } else {
        leadingWhitespace = nil
    }

    return SelectionState(
        selectionRange: cfRange,
        selectedText: selectedText,
        leadingWhitespace: leadingWhitespace
    )
}

/// Returns the leading whitespace (`/^[ \t]*/`) of the line containing
/// `cursorLocation` within `text`. Per D-03 mirror semantics. Per
/// CONTEXT.md multi-line selection note: cursor = `selectionRange.location`,
/// the START of the selection.
private static func extractLeadingWhitespace(from text: String,
                                              cursorLocation: Int) -> String {
    guard !text.isEmpty, cursorLocation >= 0 else { return "" }
    let loc = min(cursorLocation, text.count)
    let idx = text.index(text.startIndex, offsetBy: loc,
                          limitedBy: text.endIndex) ?? text.endIndex
    let lineRange = text.lineRange(for: idx..<idx)
    let line = text[lineRange]
    return String(line.prefix(while: { $0 == " " || $0 == "\t" }))
}

/// Inserts `ws` after every `\n` in `text`. No-op when `ws` is empty or
/// `text` contains no `\n`. Per D-03 (mirror only — no smart indent per D-04).
private static func injectIndent(_ text: String, leadingWhitespace ws: String) -> String {
    guard !ws.isEmpty, text.contains("\n") else { return text }
    return text.replacingOccurrences(of: "\n", with: "\n" + ws)
}
```

**Step 5.** Modify `pasteTracked(_:)`. Capture selection state FIRST (before any pasteboard mutation, per RESEARCH §System Architecture), then conditionally inject indent, then proceed:

```swift
static func pasteTracked(_ text: String) -> PasteToken {
    // Capture AX selection state BEFORE any pasteboard mutation. The
    // focused element and its selection must reflect where text will land.
    // Silent degrade on failure (D-01) — `selectionState` is nil.
    let selectionState = captureSelectionState()

    let pb = NSPasteboard.general
    let prior = pb.string(forType: .string)

    // Indent injection (D-03). Only when AX gave us non-empty whitespace
    // AND the to-be-pasted text contains \n (i.e., voice "new line" was
    // expanded by VoiceEditor). VoiceEditor stays unchanged per D-05.
    let textToWrite: String
    if let ws = selectionState?.leadingWhitespace, !ws.isEmpty, text.contains("\n") {
        textToWrite = injectIndent(text, leadingWhitespace: ws)
    } else {
        textToWrite = text
    }

    pb.clearContents()
    pb.setString(textToWrite, forType: .string)

    let changeCount = pb.changeCount
    let bundleId = NSWorkspace.shared.frontmostApplication?.bundleIdentifier

    simulatePasteKeystroke()

    return PasteToken(
        bundleId: bundleId,
        changeCountAtPaste: changeCount,
        pastedText: textToWrite,           // store the indented version
        priorPasteboardString: prior,
        timestamp: Date(),
        selection: selectionState
    )
}
```

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Frontmost app → Paster (AX read) | Paster reads the focused element's full text via `kAXValueAttribute`. Read-only. Data stays in-process. |
| Paster → NSPasteboard | Paster writes potentially-indented text. Same trust posture as today (no change). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Information Disclosure | `captureSelectionState` reads `kAXValueAttribute` (focused element's full text) | accept | Data stays in-process; not logged (D-01 silent degrade explicitly forbids logging selection/AX state); not persisted; passed only to `injectIndent` (whitespace extraction) and `PasteToken.selection.selectedText` for in-memory bookkeeping. No new attack surface vs. existing pasteboard read. |
| T-02-02 | Denial of Service | AX query blocks @MainActor on a non-responding target app | mitigate | `AXUIElementSetMessagingTimeout(element, 0.5)` per element bounds worst case to 500ms. Set on `element` not `systemWide` to avoid process-wide global change (RESEARCH Pitfall 4). |
| T-02-03 | Tampering | Stale `CFRange` from AX (text changed between range and value reads) leads to out-of-bounds index into Swift `String` | mitigate | Every `String.index(_:offsetBy:limitedBy:)` call uses `limitedBy: text.endIndex` with `?? text.endIndex` fallback. No force unwraps on offset arithmetic. Crash-resistant by construction (RESEARCH Pitfall 3). |
| T-02-04 | Information Disclosure | `selectedText` retained in `PasteToken` could leak via future logging | accept | D-01 explicitly forbids logging selection/AX state. No `NSLog` of `selection.*` permitted by linter check (verify task: `! grep -n "NSLog.*selection"`). Token lives only in `lastPasteToken: PasteToken?` on AppDelegate, scope-bounded by next dictation. |
