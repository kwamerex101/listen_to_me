## Directory Purposes

**ListenToMe/ (root):**
- Purpose: All app source code and resources
- Contains: Swift source, compiled assets, bundled binaries
- Key files: `ListenToMeApp.swift` (entry), Info.plist (metadata), ListenToMe.entitlements (permissions)

**Core/:**
- Purpose: Stateless and singleton services; pipeline stages (transcription, transformation, cleanup, paste)
- Contains: Process spawning, pasteboard/keyboard simulation, audio/haptic feedback
- Key files: WhisperRunner.swift (transcribe), CommandRouter.swift (parse), VoiceEditor.swift (edit), ClaudeClient.swift (cleanup), Paster.swift (paste+replace)

**State/:**
- Purpose: Observable data stores; @MainActor singletons for reactive UI binding
- Contains: AppState phase machine, user preferences, history/snippets/transforms JSON persistence
- Key files: AppState.swift (phase machine), HistoryStore.swift (persisted transcripts), SnippetsStore.swift (user expansions), Preferences.swift (settings)

**UI/:**
- Purpose: SwiftUI views and AppKit windows; visual rendering of state
- Contains: Animated pill (PillView), floating panels (PillWindow, CorrectionWindow), settings UI, real-time waveform
- Key files: PillView.swift (main animated UI), PillWindow.swift (always-visible), CorrectionWindow.swift (inline edit), MainView.swift (settings window), WaveformView.swift (recording feedback)

**Resources/:**
- Purpose: Bundled precompiled binaries (not source code)
- Contains: whisper-cli binary, shared libraries (.dylib)
- Generated by: setup.sh (downloads from GitHub releases, placed here)
- Committed: NO (listed in .gitignore; user runs setup.sh after clone)

**Assets.xcassets/:**
- Purpose: App icon variants for macOS
- Contains: AppIcon.appiconset/ (1x, 2x sizes for menu bar and launch)
- Compiled by: Xcode into Assets.car

## Naming Conventions

**Files:**
- PascalCase with .swift extension: `ListenToMeApp.swift`, `AudioRecorder.swift`
- Directories: lowercase: `Core`, `State`, `UI`, `Resources`, `Assets.xcassets`
- Entitlements/config: kebab-case: `ListenToMe.entitlements`, `project.yml`

**Functions:**
- camelCase verbs: start(), stop(), apply(), parse(), expand(), pasteTracked(), replace()
- Async (Task-based): clean(), transcribe(), openApplication(), runShell()
- Callbacks: onPress, onRelease, onLevel, onApply, onCancel
- Publishers/@Published: phase, level, lastTranscript, snippets, records, micGranted, claudeAvailable

**Variables:**
- camelCase: rawText, finalText, eventTap, changeCount, pasteToken, whisperPrompt
- Private prefix: _text (SwiftUI State), @State _text, @FocusState _focused
- Singletons: lowercase with .shared suffix: AudioRecorder.shared, AppState.shared

**Types:**
- PascalCase enums: Phase, WfCommand, CleanupMode, HotkeyBinding, WhisperError, ClaudeError
- PascalCase structs: WhisperRunner, CommandRouter, VoiceEditor, Paster, PasteToken, Snippet, TranscriptRecord
- PascalCase classes: AppDelegate, AppState, AudioRecorder, HotkeyMonitor, HistoryStore, SnippetsStore, Preferences
- PascalCase final classes: AudioRecorder, HotkeyMonitor, AppState (all @MainActor)

**Constants:**
- SCREAMING_SNAKE_CASE for compile-time constants: (rare in this codebase; mostly uses static let)
- static let for singleton instances: AppState.shared, AudioRecorder.shared
- Static let for string literals: Phase names, system prompts (ClaudeClient.cleanupSystemPrompt)

## Where to Add New Code

**New Feature (e.g., new voice command):**
- Primary code: `ListenToMe/Core/CommandRouter.swift` (add case to WfCommand enum, add parsing logic to parse(), add execution to execute())
- Integration: `ListenToMe/ListenToMeApp.swift:156–172` (already calls CommandRouter.parse & execute)
- Tests: `Tests/CommandRouterTests.swift` (new file; test parsing and execution)

**New Voice Edit Transform (e.g., "cap that" → capitalize previous sentence):**
- Implementation: `ListenToMe/Core/VoiceEditor.swift` (add pattern to punctuationMap or create new phase method)
- Integration: `ListenToMe/ListenToMeApp.swift:178` (already calls VoiceEditor.apply)
- Tests: `Tests/VoiceEditorTests.swift`

**New Observable Store (e.g., BookmarksStore):**
- Implementation: `ListenToMe/State/BookmarksStore.swift` (mirror SnippetsStore structure: @MainActor final class, @Published var items, persistence to ~/Library/Application Support/ListenToMe/bookmarks.json)
- Integration: Lazy-load in AppDelegate or access via BookmarksStore.shared
- UI: `ListenToMe/UI/BookmarksView.swift` (add tab to SidebarView)

**New UI Tab in Settings:**
- Sidebar entry: `ListenToMe/UI/SidebarView.swift` (add NavigationLink)
- View file: `ListenToMe/UI/[FeatureName]View.swift`
- State binding: Link to existing store (@ObservedObject var store = [Store].shared)
- Example: SnippetsView → SnippetsStore.shared

**New Feedback (sound or haptic):**
- Sound: Add method to `ListenToMe/Core/SoundCue.swift` (AVAudioPlayer + .wav file in Assets.xcassets)
- Haptic: Add method to `ListenToMe/Core/Haptics.swift` (NSHapticFeedback pattern)
- Call from: AppDelegate hotkey handlers or state phase changes

**New Singleton Service:**
- File: `ListenToMe/Core/[ServiceName].swift`
- Pattern:
  ```swift
  @MainActor
  final class [ServiceName] {
    static let shared = [ServiceName]()
    
    private init() {}
    
    func method() { ... }
  }
  ```
- Initialization: Access via [ServiceName].shared in AppDelegate.applicationDidFinishLaunching()

**New State/Preference:**
- File: `ListenToMe/State/[StoreName].swift` or add to existing Preferences/AppState
- Pattern: @MainActor final class [StoreName]: ObservableObject { @Published var property }
- Persistence: Override init() with load(), implement save() (JSON to ~/Library/Application Support/ListenToMe/)
- Binding in UI: @ObservedObject var store = [StoreName].shared
